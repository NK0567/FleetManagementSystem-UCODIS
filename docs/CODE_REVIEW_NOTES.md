# Revue du code d'origine de fms-webapp

> Ce document est destiné au développeur qui a écrit la première version de l'application. Il recense, un par un, les défauts relevés pendant la refonte, explique pourquoi ce sont des défauts et montre comment ils ont été corrigés. Les références `legacy/src/...` pointent vers le code d'origine, conservé dans le dépôt pendant la refonte ; les références `src/...` pointent vers le nouveau code.

## Comment lire chaque fiche

- **Constat** : ce qui a été trouvé.
- **Exemple** : un ou plusieurs extraits du code d'origine.
- **Pourquoi c'est un problème** : le principe en jeu.
- **Correction** : ce qui a été fait dans le nouveau code.
- **Règle à retenir** : la consigne à appliquer à l'avenir.
